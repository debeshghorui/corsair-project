# Raw Sources

Layer 1 of the LLM Wiki. Drop immutable inputs here before ingest:

- Cursor / agent session transcripts
- Design notes, meeting summaries
- Pasted research or specs

**Do not** put secrets (`.env`, API keys, tokens) in this folder.

After adding a source, ask the agent to ingest it per `AGENTS.md` → update `wiki/` pages and append to `wiki/log.md`.
